## 핵심 기여

- **반복 검토 자동화:** 메일·개발자센터·릴리즈노트 수집과 코드 검색을 Claude Cowork의 공지 수집 → 변경 선별 → 코드 대조 → 리포트 생성으로 연결했습니다. 공지 원문에서 게시일과 시행일을 구분했습니다.
- **오탐 방지:** 미사용 API 선언과 테스트·보관용 코드가 검색돼, 활성 호출 매핑과 실제 응답 필드 사용까지 확인하도록 규칙을 보완했습니다.
- **쇼핑몰별 확장:** 수집 경로·코드 단서·예외를 몰별 설정으로 분리해, 공통 절차를 수정하지 않고 검토 대상을 추가하도록 했습니다.
- **판단 근거 제공:** 출처·코드 위치·확인 불가 항목을 리포트에 남겼습니다. 최종 대응 판단과 코드 수정은 개발자가 맡도록 범위를 정했습니다.
