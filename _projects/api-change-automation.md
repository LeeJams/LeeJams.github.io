## 반복 수집을 줄이고 대응 판단은 개발자에게

쇼핑몰마다 공지 채널이 달라 원문을 찾고 연동 코드와 대조하는 데 시간이 들었습니다. **반복 수집은 자동화하되, 대응 여부를 판단할 근거는 남기는 것**을 기준으로 잡았습니다.

Claude Cowork 스킬을 수집·변경 선별·코드 대조·리포트 생성으로 나눴습니다. 상세 원문의 게시일·시행일을 구분하고, 쇼핑몰별 경로와 예외는 설정 파일로 분리했습니다.

## 코드 검색 결과를 영향 분석의 근거로 검증

미사용 상수나 보관용 파일도 검색돼, API 이름이 있다는 이유만으로 영향을 판단하면 오탐이 생겼습니다.

**상수 선언 → 활성 호출 → 응답 파싱**을 확인하도록 규칙을 보완했습니다. 테스트·보관용 코드는 제외하고, 확정할 수 없는 항목은 출처·코드 위치와 함께 확인 불가로 표시했습니다.
