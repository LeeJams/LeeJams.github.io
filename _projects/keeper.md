## 근태·급여 화면에서 업무 규칙을 검증하는 문제

Keeper는 출퇴근·스케줄·급여 등을 다루는 직원 관리 서비스입니다. 담당한 근태·급여 화면에서는 근로시간·휴게시간 계산과 주휴수당·최저임금 같은 업무 규정을 다뤘습니다.

근로시간 계산을 화면 코드와 함께 다루면 UI 수정과 계산 검증의 범위가 뒤섞입니다. 화면을 실행하지 않고도 계산 규칙을 확인할 수 있도록 책임을 나누기로 했습니다.

## 화면 표현과 계산 로직의 책임 분리

프레젠테이션/컨테이너 패턴과 Hooks를 적용해 **UI·계산·데이터 처리를 분리**했습니다. 화면은 전달받은 값과 사용자 동작을 표현하고, 계산과 데이터 처리는 각각의 로직에서 맡도록 구성했습니다.

분리한 근로시간 계산은 **Vitest 유닛 테스트**로 검증해, 화면을 실행하지 않고 업무 규칙에 따른 계산 결과를 확인할 수 있게 했습니다.

## 같은 직원 관리 기능을 네이티브 앱에 연결

이 기능은 네이티브 앱 안의 웹 화면인 WebView에서도 제공됐습니다. 웹과 앱이 데이터를 주고받아야 하므로 양쪽이 사용할 전달 인터페이스를 맞춰야 했습니다.

앱 팀과 데이터 전달 인터페이스를 협의해 **WebView 브릿지**를 구현하고, 직원 관리 웹 기능을 네이티브 앱의 사용 흐름에 연결했습니다.
