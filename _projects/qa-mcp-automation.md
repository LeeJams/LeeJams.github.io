## 핵심 기여

- **API 기반 QA:** 여러 화면을 오가던 상품 준비·전송 테스트를 사용자 화면과 같은 API로 연결했습니다. 화면 구조 변경의 영향을 줄이도록 API를 MCP 도구로 구성했습니다.
- **실행 범위 제한:** AI가 상품 생성과 외부 전송까지 수행하므로 API 주소·메뉴를 허용 목록으로 제한하고, DB 직접 접근은 읽기 전용으로 강제했습니다. QA 서버가 확인되지 않은 채널은 사람이 허용한 뒤 전송하도록 했습니다.
- **재시도 정합성:** 실패 때 새 상품을 만드는 동작을 제한하고, 동일 상품에서 실패 원인·수정값을 남겨 다시 전송하도록 했습니다. 채널이 상품번호를 발급한 경우 신규 재전송을 차단했습니다.
- **팀 공용 검토:** 요청·응답·채널 원문·변경값을 실시간 모니터와 상품 이력에 기록했습니다. 팀이 같은 실행 기록과 해결 노하우를 확인하고, AI도 다음 테스트 전에 이를 읽도록 했습니다.
