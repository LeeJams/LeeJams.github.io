## 핵심 기여

- **QA 실행 절차 설계:** 브라우저 조작 스킬로 사용하던 절차를 바탕으로, 상품 생성·수정·전송·이력 조회를 기존 API 기반 도구로 구성했습니다. 테스트 조건은 바꿔 요청하되 반복되는 준비 절차는 도구에서 처리하도록 했습니다.
- **MCP 서버 구성:** Claude Code·데스크톱 앱·Cowork에서 같은 QA 도구를 연결하도록 구성했습니다. 개인 PC에서 시작해 공용 서버로 옮겼습니다.
- **실행 범위 제한:** API 주소·메뉴를 허용 목록으로 제한하고, DB 직접 접근은 읽기 전용으로 강제했습니다. 테스트용 전송 대상이 확인되지 않은 채널은 사람이 허용한 뒤 전송하도록 했습니다.
- **실행 결과 검토:** 요청·응답·채널 원문·변경값을 실행 모니터와 상품 이력에 기록했습니다. 같은 상품의 실패·값 수정·재전송을 이어서 확인하도록 했습니다.
