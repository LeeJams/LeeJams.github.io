## 핵심 기여

- **달력보다 운영 규칙을 먼저 고려:** 고객사의 조건에 맞는 라이브러리를 찾기 어려워 캘린더 동작을 직접 구현했습니다. 설정된 시점과 휴일 규칙에 따라 선택 가능한 날짜를 제어하고, 날짜를 선택하면 설정된 예약 시간 목록이 활성화되도록 연결했습니다.
- **화면별 API 호출의 공통 처리:** 각 화면에서 손쉽게 API를 호출할 수 있도록 Axios 공통 통신 유틸리티를 정의했습니다. 요청·응답 인터셉터에 오류 처리와 토큰 유효성 체크를 두어 통신 과정에서 필요한 처리를 함께 관리했습니다.
- **개발 환경의 초기 구성:** 개발 서버를 빠르게 띄우고 변경을 확인할 수 있도록 Vite로 고객·관리자용 프로젝트를 구성했습니다. Vue 3·TypeScript·Pinia 기반에서 화면 구현을 시작할 수 있도록 개발 환경을 세팅했습니다.
