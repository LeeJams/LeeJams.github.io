회사·서비스의 로고와 상표 권리는 각 소유자에게 있습니다. 이 문서의 회사명·설명은 프로젝트 당시의 조직 정보를 변경하지 않습니다.

비즈니스 센터 예약 관리와 브랜드 페이지·CMS 프로젝트에도 같은 리만코리아 로고를 사용합니다. My Pack의 서비스 명칭은 [한국암웨이 2021년 1월 공식 아마그램](https://media.amway.co.kr/sys-master/images/h53/hc3/9097134735390/pdf_210105_amagram_january.pdf)에서도 확인했으며, 역할·기간·구현 내용은 작성자가 제공한 경력을 기준으로 정리했습니다.
