미로 돌파 개인정보처리방침

LeeJam은 Android 게임 미로 돌파의 순위 기능을 운영하기 위해 아래와 같이 정보를 처리합니다.

기기에 저장하는 정보

게임에서 정한 닉네임, 스테이지 진행 상황과 설정은 기기에 저장됩니다. Android의 앱 정보에서 저장공간을 지우면 이 정보도 삭제됩니다.

탈출 기록을 등록할 때 보내는 정보

탈출 후 기록 등록을 누르면 닉네임, 스테이지, 해당 플레이를 구분하는 임의 식별자, 시작 지점과 출구, 이동 등 플레이 입력 정보가 순위 서버로 전송됩니다. 서버는 플레이를 검증해 탈출 시간을 계산하고, 같은 기록이 중복 등록되는 것을 막습니다. 기록을 등록하지 않아도 미로를 플레이할 수 있습니다.

스테이지별 공개 순위에는 닉네임과 탈출 시간이 표시됩니다. 순위에 공개해도 되는 닉네임을 사용해 주세요.

서버 운영과 보안

순위 서버는 Supabase의 호스팅 및 데이터베이스 서비스를 이용합니다. 앱과 순위 서버 간 통신은 HTTPS로 암호화됩니다. 이 버전에는 별도의 로그인 계정, 인앱 결제, 광고 SDK가 없습니다.

보관과 삭제

기록 검증에 사용한 플레이 입력 정보는 순위 데이터베이스에 저장하지 않습니다. 서버에는 중복 등록 방지와 순위 표시를 위해 플레이 식별자, 스테이지, 닉네임, 탈출 시간과 기록 처리 시각이 남습니다. 해당 기록에 별도의 자동 삭제 기한은 설정되어 있지 않습니다. 기기의 앱 데이터를 지워도 이미 등록한 순위 기록은 서버에 남습니다.
